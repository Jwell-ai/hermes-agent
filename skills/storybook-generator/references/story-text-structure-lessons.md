# Page-Level Text Structure Lessons

This note summarizes text mechanics and page-turn mechanisms. It does not reuse source-book wording.

## Write Sentence Function Before Draft Text

Do not write page copy immediately. First label the sentence function:

- `statement`: states one clear action.
- `question`: turns a static scene into a task.
- `repetition`: creates read-aloud rhythm.
- `cumulative_repetition`: adds one variable per page.
- `dialogue`: lets conflict appear through character speech.
- `sound_word`: makes action rhythmic.
- `action_trigger`: small action triggers next page.
- `discovery`: reveals the source of a misunderstanding.
- `reversal`: ending language or meaning reversal.

Page text has one job: move action, ask a question, name a discovery, or create a page turn. It must not merely explain the picture, and must not explain something absent from the picture.

Common high-frequency patterns in reference books:

- short action sentences
- dialogue
- repeated sentences
- cumulative escalation
- sound words
- reversal
- questions

Every draft page should have at least one sentence function and one page-turn mechanism.

## Task Chain, Not Emotion Pile

For bedtime/fear themes, use a task chain:

1. Adult or situation introduces bedtime/darkness.
2. Protagonist cannot settle because something remains unresolved.
3. Each object/companion/shadow gives a specific reason.
4. Protagonist uses an imaginative or practical action to handle one item.
5. One item resolves, another problem escalates.
6. Protagonist becomes increasingly active.
7. Ending reframes the original problem.

For fear of the dark:

adult leaves -> protagonist sees a shadow -> checks with flashlight -> finds ordinary source -> names/places the shadow -> next shadow appears -> protagonist reuses method -> sleeps.

Do not write: fear -> more fear -> adult comfort -> not afraid. Every 2-3 pages needs visible progress: observe, verify, name, arrange, reuse.

## Repetition Must Add Variables

Good repetition uses a fixed shell plus a new drawable variable.

Example pattern:

- There is a house.
- In the house is a bed.
- On the bed is a person.
- On the person is a child.
- On the child is a dog...

Then the chain reverses as events trigger each other.

Rule:

- repeated sentence = fixed shell + new variable
- new variable must be drawable
- later pages can reverse the cumulative chain

If repetition only swaps adjectives and adds no visible variable, rewrite it.

## Short Lines Can Create Strong Page Turns

One short sentence can force a page turn:

- "The little shadow moved,"
- "Anan lifted the flashlight,"
- "The curtain puffed softly,"
- "The fish on the wall swam,"

The next page reveals cause or result.

Every page must have `page_turn_hook`. Without a hook, merge or rewrite.

## Questions Are Useful For Young Readers

Questions turn adult commands into child tasks:

- "But whose corner is that on the wall?"
- "What happens if the flashlight shines there?"
- "Is that fish really a fish?"

Use questions to turn a static image into a solvable action.

## Text And Image Divide Labor

Good pages do not need much text. Text provides action, rhythm, question, or turn; image provides atmosphere, relationship, and detail.

Rules:

- Do not restate everything the image already shows.
- Text should add action/problem/turn, not adjectives.
- Complex image -> shorter text.
- Static image -> use repetition, sound, or question to add rhythm.

## End With A Language Echo Or Reversal

Prefer echo/reversal over moral summary.

Examples:

- "Who is the night inspector now?" "Me... and the inspector who knows how to sleep."
- "The shadows did not leave. They lined up and quieted down."
- "Anan closed her eyes. The little flashlight clocked out too."

## Draft Checklist

- Does each page have one action, question, discovery, or turn?
- Is sentence function labeled before text?
- Does repetition add a new variable?
- Can every new variable be drawn?
- Are there at least 2-3 short page-turn hooks?
- Does every page have `page_turn_hook`?
- Is there at least one question that pushes the plot forward?
- Does the ending use echo/reversal instead of adult moralizing?
- Can the text be drawn?
- Does text move the story rather than explain missing image content?
- Are any two consecutive pages only emotion with no action? Rewrite if yes.
