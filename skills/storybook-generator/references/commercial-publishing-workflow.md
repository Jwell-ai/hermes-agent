# Commercial Publishing Workflow

Use this when the user wants Amazon KDP, a sellable manuscript, a series product, commercial validation, cover copy, store description, or a low-cost market test.

## Goal

Move from "can be made" to "can be validated, listed, and reused".

## 1. Validate The Concept First

- Make a low-cost version before investing in full premium illustration.
- Check whether the topic has a real purchase reason.
- If the concept is weak, change the topic before polishing visuals.

## 2. Treat The Book As A Product Chain

1. topic and target age
2. story structure and page rhythm
3. character bible and visual continuity
4. page illustrations
5. cover
6. KDP / platform description
7. series expansion
8. layout and export

## 3. Every Step Serves The Purchase Reason

- Topic answers: why would a parent buy this?
- Cover answers: what problem does this book solve?
- Description answers: what benefit does the child/family get?
- Series plan answers: why would they buy the next one?

## 4. Build The Minimum Sellable Version First

- Create a simplified sample book before investing in higher-quality art.
- If the sample gets no useful response, adjust topic, positioning, or page rhythm first.
- If the sample works, upgrade illustrations, cover, and layout.

## Controlled Skill Integration

Keep:

- topic -> story -> character -> illustration -> cover -> description -> series -> layout
- validate first, invest later
- cover and description serve parent purchase reason

Do not turn this into a marketing course. Use it only as the commercial branch of the storybook workflow.
